ATM Management System (Java)
Description
This is a simple ATM Management System built using Java.
It simulates basic ATM operations such as checking balance, depositing money, and withdrawing cash.
Features
User login using PIN
Check account balance
Deposit money
Withdraw money
Exit option
Technologies Used
Java
OOP concepts
Console-based application
How It Works
User enters ATM PIN
Menu is displayed
User selects an option
Transaction is processed
Updated balance is shown
How to Run
Install Java (JDK)
Compile the program using javac
Run the program using java
Follow on-screen instructions
Example Operations
Balance Inquiry
Cash Deposit
Cash Withdrawal
Use Case
This project is useful for learning Java basics, OOP concepts, and menu-driven programs.
